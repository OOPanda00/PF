# Panda Finance

Personal finance tracker for Android, built with Kotlin, Jetpack Compose, Room and DataStore.

## v1.8.0
- Arabic / English with RTL support
- Available balance, obligations and receivables
- Partial payments and receipts
- Reserve-aware payment suggestions
- Account details, due dates and reminders
- Local backup / restore
- Dark mode
- GitHub Actions APK build and tag releases
- Unit tests for the financial suggestion engine

## GitHub Actions
Push to `main`/`master` to build a debug APK. Push a tag such as `v1.8.0` to create a GitHub Release containing the APK.
